# 多段フォワードプロキシシステム構築ポートフォリオ

多段フォワードプロキシ構成を題材にした、学習・検証用のポートフォリオです。  
設計意図から、動作確認に用いた検証エビデンスまで整理しています。

※本ポートフォリオは、学習・検証目的で作成した独自構成です。  
実在する企業・顧客・現場環境・設定値・ネットワーク構成を示すものではありません。  
記載している構成図・名称・経路は、技術理解を説明するために一般化・抽象化したものです。

---

## ① 設計意図・全体構成

- 多段プロキシ構成の設計背景
- 経路制御（PAC）、復号（SSLBump）、中継TLS（stunnel）の役割分離
- 認証（AD / LDAP / Kerberos）およびログ基盤の位置付け
